## Hướng dẫn chạy

Cài JDK 8 trở lên. Mỗi câu là một chương trình độc lập. Ví dụ, để chạy câu 2, mở terminal tại thư mục chứa README và nhập lần lượt các lệnh sau.

```sh
cd Cau2
javac -encoding UTF-8 Main.java
java Main
```

Nhập dữ liệu từ bàn phím theo định dạng của câu đang chạy. Ví dụ với câu 2, nhập số sinh viên ở dòng đầu, tiếp theo là mã hệ, mã sinh viên và số tín chỉ.

```text
1
CQ B25DCCC173 18
```

Kết quả tương ứng với 18 tín chỉ chính quy, đơn giá 450.000 đồng mỗi tín chỉ.

```text
B25DCCC173 CQ 8100000
```

Để chạy câu khác, quay lại thư mục gốc bằng `cd ..`, vào thư mục `Cau1`, `Cau3` hoặc `Cau4`, rồi chạy lại hai lệnh `javac` và `java` ở trên.
